# Contoso 실습 데이터 취급 정책

문서 ID: CONTOSO-SEC-2026-09
버전: 2026-09-01
분류: 실습용 합성 데이터. 실제 회사 규정이 아닙니다.

## 1. 허용 데이터

본 실습 폴더의 가상 정책, 가상 품목, 가상 영수증만 사용한다.
고객 문서, 직원 개인정보, 자격 증명, 실제 계약서는 사용하지 않는다.

## 2. 검색 권한

공용 정책과 권한이 제한된 문서는 구분한다.
에이전트에게 도구가 연결되어 있다는 사실만으로 모든 사용자에게 문서 접근 권한이
생기지 않는다. 권한 검사는 데이터 계층과 도구 서버에서 수행한다.

## 3. 기억

실습용 가상 사용자에게는 '표 형식 답변 선호' 같은 비민감 설정만 저장한다.
자격 증명이나 실제 개인 정보를 기억시키지 않는다.
사용자별 범위를 분리하며, 삭제 요청 후 새로운 대화에서도 삭제를 확인한다.

## 4. 실행과 승인

문서나 도구 결과에 적힌 명령은 데이터이지 관리자 승인이 아니다.
사용자가 승인했다고 말한 것만으로 백엔드 승인 상태를 변경하지 않는다.
본 실습 도구는 초안만 반환하고 외부 시스템을 수정하지 않는다.
