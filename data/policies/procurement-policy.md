# 한빛 오피스 구매 정책

문서 ID: HB-PROC-2026-09
버전: 2026-09-01
분류: 실습용 합성 데이터. 실제 회사 규정이 아닙니다.

## 1. 적용 범위

한빛 오피스 직원의 업무용 장비 구매에 적용한다. 이 문서는 가격 상한과
승인 규칙을 정의하며, 현재 재고나 실시간 가격을 보장하지 않는다.

## 2. 품목별 상한

가격은 원화(KRW)이며 부가가치세를 포함한다.

| 품목 | 1개당 상한 |
| --- | ---: |
| 표준 노트북 | 1,500,000원 |
| 모니터 | 350,000원 |
| 키보드 | 120,000원 |

개인 취향에 따른 상한 초과는 자동 승인되지 않는다.
표준 노트북의 정기 교체 주기는 지급일로부터 36개월이다.
고장·분실에 따른 예외는 IT 담당자의 개별 검토가 필요하다.

## 3. 승인 규칙

주문 총액이 2,000,000원 이하이면 팀장 승인,
2,000,000원을 초과하면 팀장과 구매 담당자 승인이 모두 필요하다.
2,000,000원과 정확히 같을 때는 팀장 승인이 필요하다.
초안 생성은 승인이 아니며, 승인도 주문 완료를 의미하지 않는다.

## 4. 재고와 주문

재고 수량과 단가는 재고 조회 도구의 결과를 사용한다.
조회 실패 시 재고나 납기를 추측하지 않는다.
재고가 부족하면 부족 사실과 확인 가능한 납기를 설명하고 추가 안내를 요청한다.
실습 시스템은 구매 요청 초안만 만들며, 실제 주문이나 결제를 하지 않는다.

## 5. 근거 없는 질문

이 문서에 없는 해외 지사 규정, 개인별 급여, 공급사 계약 정보는 추측하지 않는다.
담당 부서에 확인이 필요하다고 안내한다.
