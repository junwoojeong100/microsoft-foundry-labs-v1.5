# Contoso 구매 요청 초안 검토

1. 정책 도구의 실제 결과에서 문서 ID와 절을 확인한다.
2. 재고와 단가는 `get_stock` 결과만 사용한다.
3. 수량이 없거나 1~10의 정수가 아니면 확인을 요청한다.
4. 초안 총액이 2,000,000원 이하이면 팀장, 초과이면 팀장과 구매 담당자의
   승인이 필요하다. 정확히 2,000,000원은 초과가 아니다.
5. 결과를 `결론 / 근거 / 다음 단계`로 작성한다.
6. 초안 생성, 업무 승인, 실제 주문·결제는 서로 다른 상태다.
   이 실습은 초안에서 멈춘다. 승인·주문·결제 완료로 바꾸지 않는다.

이 skill에는 실행 스크립트가 없으며 권한을 부여하지 않는다.
