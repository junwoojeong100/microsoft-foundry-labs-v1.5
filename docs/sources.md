## 공식 문서 활용하기

개념은 Microsoft Learn의 개요와 capability reference에서, 사용 조건은 해당 기능 문서와 GA 표에서 확인합니다.
이 학습 경로는 Azure portal·Foundry portal만 사용합니다. 공식 문서의 SDK/API 지원이 포털 버튼·필드 지원을 뜻하지 않습니다. 새 포털의 GA와 개별 기능의 GA도 다를 수 있습니다.
